# Product container telemetry

Convy System shows the API, worker, authentication, dashboard, MCP and PostgreSQL containers. Shared Caddy, Dokploy and Converso belong to Infrastructure Ops. CPU uses Docker's convention (100% is one core); memory is Docker's reported working set, rounded by the existing CLI collector. A running container without a configured healthcheck has unknown health.

The existing host Ops collector publishes `/var/lib/shared-host-ops/products/convy/current.json`. Mount only that directory read-only into the API and worker at `/run/convy-container-metrics`. The dashboard reads its existing authorized admin API. Neither application receives the Docker socket, host publications, another product's directory or credentials. The reader bounds input to 16 KiB and validates product, scope, six exact container names, unique Docker identities, numeric values and capture time. Missing, malformed, future or older-than-180-second telemetry remains unknown/stale without host fallback.

The additive `AddContainerMetricScope` migration gives existing snapshots `metric_scope=legacy-host` and a null container payload. Existing values are retained. New worker snapshots have `metric_scope=container`, container identities/measurements and null host-resource fields; PostgreSQL database size remains application information. Charts use separate labels and units with gaps across missing samples. Existing 30-day retention is unchanged.

For the migrated host, merge the small metrics Compose override into the exact native Dokploy application configuration under the existing reviewed manual release procedure. Preserve application names, database mounts, networks, credentials, resource limits and the shared edge overrides. Build immutable images away from the VPS, pass exact-source CI, retain the old API/worker/dashboard image digests and verify a current backup before deployment. Roll application images back on failed acceptance while retaining the additive schema and new history; schema downgrade is only tested on disposable data and would remove the new container payload columns.
